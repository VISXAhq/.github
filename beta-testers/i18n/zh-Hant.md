# 參與 VISXA 英國標準訪客簽證準備服務測試

_Langue / Language: 繁體中文（國語／普通話）. Public translation for information only; official English/Arabic website remains the authoritative source for current availability._

VISXA, Inc. 正邀請志願者測試英國 Standard Visitor（標準訪客）簽證申請準備服務。目前提供英語與阿拉伯語體驗，測試僅限受邀者參加，初期以埃及為重點，也歡迎其他國家的使用者表達興趣。

獲選並確認參與測試的人員，可免除 VISXA 本身的申請準備服務費。此項優惠不包括英國政府簽證申請費、簽證中心收費、翻譯費或其他第三方費用。

目前僅使用模擬文件測試。請勿上傳真實護照、財務資料或個人簽證案件資訊；現階段不提供真實簽證申請遞交服務，也不保證獲得簽證。

請透過 VISXA 官方網站加入候補名單。一般性建議可在 GitHub 提出，但請勿公開個人資料。VISXA 為獨立的美國公司，與英國政府機關無隸屬關係，亦不提供移民法律意見。
