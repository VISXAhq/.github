# 参加 VISXA 英国标准访客签证准备服务的测试

_Langue / Language: 简体中文（普通话）. Public translation for information only; official English/Arabic website remains the authoritative source for current availability._

VISXA, Inc. 正邀请志愿者测试其英国 Standard Visitor（标准访客）签证申请准备服务。现阶段提供英语和阿拉伯语体验，测试仅限受邀者参加，初期重点面向埃及，也欢迎其他国家的用户表达兴趣。

获选并确认参加测试的人员，可免除 VISXA 自身的申请准备服务费。此优惠不包括英国政府签证申请费、签证中心费用、翻译费或其他第三方费用。

目前仅使用模拟文件进行测试。请勿上传真实护照、财务材料或个人签证申请信息；现阶段不提供真实签证申请递交服务，也不保证获得签证。

请通过 VISXA 官方网站加入候补名单。一般性建议可在 GitHub 上提出，但不要公开个人信息。VISXA 是独立的美国公司，不隶属于英国政府机构，也不提供移民法律意见。
